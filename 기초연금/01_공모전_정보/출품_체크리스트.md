# AI 이미지 출품 체크리스트

## 기획

- [ ] 네 가지 공모 주제 중 하나와 명확히 연결된다.
- [ ] 핵심 메시지를 한 문장으로 말할 수 있다.
- [ ] 첫 2초의 인상이 긍정적이다.
- [ ] 5~10초 안에 핵심 정보를 읽을 수 있다.
- [ ] 세부 정보는 핵심 메시지와 시각적으로 분리되어 있다.
- [ ] 기초연금 관련 정보는 공식 자료로 사실 확인했다.

## 제작·권리

- [ ] 사용한 모든 AI 도구와 활용 범위를 기록했다.
- [ ] 최종 프롬프트와 주요 수정 과정을 보관했다.
- [ ] 원본·편집 파일과 버전별 결과물을 보관했다.
- [ ] 사용한 폰트, 이미지, 아이콘의 라이선스를 확인했다.
- [ ] 특정 인물·브랜드·기존 작품을 모방하지 않았다.
- [ ] 초상권과 제3자 권리를 침해하는 요소가 없다.
- [ ] 타 공모전에 출품하지 않았고 공개·유포하지 않았다.

## 가독성·출력

- [ ] 결과물의 한 변이 최소 1,000픽셀 이상이다.
- [ ] 작은 화면과 멀리서도 핵심 카피가 읽힌다.
- [ ] SNS와 전광판 환경에서도 메시지가 유지된다.
- [ ] JPG/JPEG/PNG/PDF 중 허용 형식이다.
- [ ] 파일 용량이 500MB 미만이다.
- [ ] 오탈자, 숫자, 날짜, 기관명을 최종 검수했다.

## 접수

- [ ] 영상·이미지 합산 1인 최대 2작품 제한을 지켰다.
- [ ] 개인 명의로 접수한다.
- [ ] 작품 설명에 AI 활용 여부·도구·범위를 기재했다.
- [ ] 작품 원본, 제작 과정, 프롬프트를 제출 요구에 대비해 정리했다.
- [ ] 접수 후 마감 전에 업로드 파일을 다시 확인했다.
- [ ] 스펙토리 회원가입을 원치 않으면 기본 체크를 해제했다.
- [ ] 2026-09-16 18:00 이전에 최종 접수를 완료했다.
