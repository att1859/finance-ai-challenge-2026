# 한결 재난금융 지원센터

금융기관 담당자가 재난 공지를 AI로 구조화하고, 잠재 피해 고객을 선별해 인증된 은행 앱의 신청·서류 제출·심사 이관까지 연결하는 데모입니다.

## 실행

```sh
npm install
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다.

## 실제 AI 분석 활성화

`.env.example`을 참고해 프로젝트 루트의 `.env`에 `OPENAI_API_KEY`를 설정하세요. 키가 없거나 API 호출에 실패하면 저장된 분석 결과로 동일한 데모 흐름이 계속 동작합니다.

## 주의

- 모든 고객 및 거래 정보는 합성 데이터입니다.
- 지원제도는 공식 자료를 바탕으로 구성했지만 실제 신청 전 해당 기관의 최신 공고와 심사가 필요합니다.
- 본 데모는 자동 승인·지급을 수행하지 않습니다.
