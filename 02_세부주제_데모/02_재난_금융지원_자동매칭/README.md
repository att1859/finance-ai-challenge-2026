# 한결 재난금융 지원센터

재난 피해를 입은 고객을 은행이 먼저 찾아 지원제도 3가지를 안내하고, 고객이 은행 앱에서 바로 신청하도록 연결하는 PC 우선 데모입니다.

## 시연 흐름

1. 데모 컨트롤에서 침수·산불·폭설 중 하나를 선택합니다.
2. 담당자 화면에서 재난 공지를 분석하고 검토 완료합니다.
3. 추천 고객을 검색·필터링해 한 명을 선택하고 고객 앱에 안내합니다.
4. 고객 화면으로 전환해 피해 내용을 확인하고 신청서를 제출합니다.
5. 담당자 화면에서 은행 접수와 심사 이관을 차례로 완료합니다.

담당자와 고객 화면은 하나의 데모 안에 있지만, 실제 제품처럼 서로 다른 역할의 화면으로 분리되어 있습니다. 역할·시나리오 전환과 초기화는 제품 기능이 아닌 상단의 `데모 컨트롤`에서만 제공합니다.

## 실행

```sh
npm install
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다. 다른 개발 서버가 사용 중이면 Vite가 다음 포트를 자동으로 선택합니다.

## 실제 AI 분석 활성화

`.env.example`을 참고해 프로젝트 루트의 `.env`에 `OPENAI_API_KEY`를 설정하세요. AI는 입력 문장을 정해진 피해 항목으로 분류하고 추천 근거를 만드는 데 사용합니다. 키가 없거나 호출에 실패하면 화면에 그 사실을 알리고 저장된 분석 결과로 같은 흐름을 계속 시연합니다.

## 문서

- `PRODUCT.md`: 제품 목표와 역할 구조
- `SPEC.md`: 화면·기능 상세 명세
- `USER_FLOWS.md`: 담당자·고객 시연 흐름
- `COPY.md`: 역할별 용어와 문구 원칙
- `DATA_SCHEMA.md`: 시나리오·고객·상태 데이터 구조
- `ACCEPTANCE.md`: 완료 조건과 검증 기록
- `IMPLEMENTATION_PLAN.md`: 구현 순서와 범위

## 주의

- 모든 고객 및 거래 정보는 합성 데이터입니다.
- 지원제도는 공식 자료를 바탕으로 구성했지만 실제 신청 전 해당 기관의 최신 공고와 심사 기준 확인이 필요합니다.
- 본 데모는 자동 승인·지급을 수행하지 않습니다.
