# 한결 재난금융 지원센터

## Product

재난 발생구역과 은행의 합성 고객 사업장·대출상품·상환일정을 연결해 잠재 피해고객의 내부 지원 케이스를 먼저 만들고, 인증된 은행 앱에서 고객이 피해확인과 신청을 시작하도록 돕는 금융기관용 웹 MVP다.

## Users

- 주 사용자: 한결은행 재난지원·고객보호·여신관리 담당자
- 보조 사용자: 한결은행 고객 앱에서 안내를 확인하고 서류를 제출하는 합성 고객

## Core Flow

재난 선택 → AI 지원공지 구조화 → 담당자 승인 → 잠재고객 선별 → 대표 지원 3개 확인 → 고객 앱 노출 → 고객 서류 제출 → 심사부서 이관

## Constraints

- 침수 피해 카페, 산불 피해 숙박업, 폭설 피해 시설농가의 세 가지 시나리오가 모두 동작한다.
- 고객·대출·사업장·피해정보는 전부 합성 데이터다.
- 지원제도는 실제 공식 제도에 기반하지만 접수 가능 여부와 최종 자격은 기관 심사를 거친다.
- AI는 공지와 고객 서술을 구조화한다. 지역·상품·상환일 매칭과 상태 전환은 규칙 기반이다.
- 자동 승인이나 지급을 표현하지 않는다. 신청 완료는 은행 또는 외부기관 심사 이관까지다.
- 실제 API 키가 없거나 호출에 실패하면 같은 스키마의 저장된 분석 결과를 사용한다.

## Visual Direction

Seed Design System을 사용한 데스크톱 우선 운영형 화면이다. 재난 대응 상황실의 선명한 상태 구분과 하나의 케이스가 끊기지 않고 이동하는 진행선을 핵심 경험으로 삼는다. 화면 배치는 특정 레퍼런스를 복제하지 않고 작업 상태·근거·다음 행동의 우선순위를 따른다.
