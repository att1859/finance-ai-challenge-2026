# 시나리오 로직 플랜

상태: 보류 · 사용자 요청으로 남긴 검토 메모. 현행 제품 기준이나 구현 확정안이 아니며, 별도 재개 요청 전에는 구현하지 않는다.

- 각 시나리오에서 일반 상환·취업 후 상환 여부를 명확히 표시한다. 등록금과 생활비의 상품이 다르면 용도별로 구분한다.
- ‘취업 후 상환이 가능하면 우선 추천하고, 불가능하면 일반 상환을 제시’하는 방식이 적절한지 검토한다. 아직 추천 원칙으로 확정하지 않는다.
- 상품 이용 자격과 사용자에게 적합한 상품 추천을 분리한다. 자격 미확인은 이용 불가로 단정하지 않는다.
- 어떤 사용자에게 어떤 구성을 추천할지 정한다. 검토 항목은 지원구간·학적 등 자격, 이자면제·상환유예 적용 여부, 취업 시점과 예상 소득, 재학 중 납입 여력, 상환기간, 총이자·잔액과 사용자 선호다. 공식 정책을 확인한 뒤 조건별 기준과 예외를 정한다.
- 기본 세 시나리오와 사용자 추가 시나리오에 적용할 상품 선택·추천 규칙, 추천 이유와 대안 표시 방식을 함께 설계한다. 근로시간·학기당 생활비 대출액 설정과 상품 추천의 관계도 정리한다.

재개 시 산출물: 사용자 조건별 추천 기준표, 필요한 입력 항목, 시나리오별 상품 표시안 및 검증 사례.
