# 학자금 소비평탄화

대학 재학 중 생활·학업시간과 졸업 후 상환 부담을 함께 비교하는 계획 도구의 핵심 용어를 정의한다.

이 문서는 현재 구현에서 사용하는 제품 용어를 설명한다. 현재 동작은 `PRODUCT.md`, 계산·판정의 코드 경계는 `ARCHITECTURE.md`와 구현 코드·테스트를 따른다.

## Language

**월 희망 생활비**:
사용자가 대학 재학 중 한 달에 확보하고 싶은 생활비다. 최초 기본값은 80만 원이다.
_Avoid_: 생활비 대출액, 현재 생활비

**현재 월소득**:
용돈·기존 소득·저축 중 매달 생활비로 쓸 수 있는 금액. 앞으로 추가로 할 알바와 대출은 제외한다.

**생활비 보완 추가 알바 시간**:
희망 생활비에서 현재 월소득과 생활비 대출의 월 배분액을 뺀 부족분을 최저시급으로 단순 환산한 월 시간. 등록금은 바로 납부해야 하므로 이 시간에 포함하지 않는다. 원시값은 유지하고 표시에서만 정수 반올림한다. 실제 근로조건·실수령액 추정이 아니다.

**등록금 대출**:
학기당 실제 납부 등록금을 충당하기 위한 학자금대출 금액이다.
_Avoid_: 생활비 대출, 신규 대출 총액

**대출 없이 낼 수 있는 등록금 금액**:
이번 학기 실제 납부 등록금 중 부모님 지원·이미 저축한 돈으로 낼 수 있는 금액이다. 향후 알바·대출금과 생활비로 배정한 금액은 제외한다. 실제 납부 등록금보다 클 수 없다.
_Avoid_: 장학금, 등록금 대출

**생활비 대출**:
대학 재학 중 생활비를 충당하고 생활비 여력을 늘리기 위해 사용하는 학자금대출 금액이다. 이용 가능 여부에는 소득분위 조건이 적용될 수 있다.
_Avoid_: 등록금 대출, 월 희망 생활비

**현재 중시**:
이번 학기 등록금 전액과 생활비 대출 한도를 활용하는 안.

**균형**:
등록금은 최소 대출과 전액의 중간값, 생활비는 월 희망액에서 현재 월소득을 뺀 부족분을 빌리는 안. 생활비 대출에는 거치이자를 더하지 않는다. 공식 최소액·5만 원 단위·한도로 희망액과 차이가 날 수 있다.

**미래 중시**:
이번 학기 등록금 부족분만 빌리고 생활비 대출을 받지 않는 안.

**NO 대출**:
기존·신규 대출이 모두 없는 별도 막대 비교 기준. 등록금 부족분은 납부 전에 따로 마련해야 하며 추가 알바를 이미 했다고 가정하지 않는다.

**남은 학기와 이번 학기**:
남은 학기는 이번 학기 포함 졸업까지의 기간으로 이자·거치 계산에 쓰인다. 신규 등록금·생활비 대출은 이번 학기에만 실행한다.

**풀대출 상한 보기**:
학기 한도와 학제별 누적한도를 적용해 받을 수 있는 생활비 대출의 최대 원금을 보여주는 참고값이다. 추천 시나리오가 아니다.
_Avoid_: 최대활용안, 추천안

**신규 대출 구성**:
하나의 시나리오에서 새로 이용하는 등록금 대출 실행분과 생활비 대출 실행분의 조합이다. 상품·용도 구분 없는 합계는 구성 자체가 아니라 표시용 요약이다.
_Avoid_: 신규 대출(상품 구분 없이 합계만 가리킬 때)

**상품 구성 설명**:
추천 후보의 등록금·생활비 상품, 금액, 자격 상태, 추천·주의·제외 이유와 계산 정책근거를 사용자가 확인할 수 있는 문장과 항목으로 묶은 결과다.
_Avoid_: 상품명만 있는 대출 합계, 내부 추천 점수

**대출 실행분**:
한 학기의 한 자금용도에 하나의 상환상품으로 실행되는 대출 단위다. 상품, 용도, 원금, 학기, 예상 실행일, 자격 상태와 정책근거를 독립적으로 가진다.
_Avoid_: 신규 대출 총액, 상품·용도 구분 없는 대출

**공식 대출정책 스냅샷**:
특정 학기의 금리, 한도, 자격, 특례, 상환 기준과 효력일·확인일·공식 출처를 함께 보존한 읽기 전용 로컬 정책값이다. 현재 기준 스냅샷 ID는 `kosaf-2026-2`다.
_Avoid_: 최신 정책 API, 정책 상수 모음

**계산 정책근거**:
한도·자격·금리·상환 계산에 실제 사용한 정책값과 기준학기, 효력일, 확인일, 공식 출처를 묶은 `policyReferences` 항목이다.
_Avoid_: 일반 안내 링크, 출처 없는 기준값

**용도별 혼합 구성**:
동일 학기의 등록금과 생활비에 서로 다른 상환상품을 배정한 신규 대출 구성이다. 등록금과 생활비는 별도 실행·전환할 수 있으므로 각 구성요소가 해당 상품의 자격을 개별 충족할 때 후보로 허용한다.
_Avoid_: 한 용도에 여러 상품을 임의로 합산한 대출

**자격 판정 상태**:
현재 입력과 정책 기준의 결과로, 충족은 `eligible`, 추가 조건 확인이 필요하면 `conditional`, 확인된 조건을 충족하지 못하면 `ineligible`, 핵심 정보가 부족하면 `unknown`이다. 실제 신청 승인이나 추천 여부를 뜻하지 않는다.
_Avoid_: 승인 결과, 추천 여부

**추천 대출 구성**:
한 시나리오 안에서 자격·자금충족·목표·상환 안전성 규칙을 통과하고 같은 등급 후보의 비용 비교까지 거친 상품·용도 조합이다. 시나리오 전체의 순위나 실제 승인을 뜻하지 않는다.
_Avoid_: 추천 시나리오, 승인 대출

**추천 설명**:
추천·조건 확인의 이유, 생활비 대출의 월 생활비 증가 효과와 현재 기준 10년 비교의 잔액·변동금리·자격 주의를 계산 결과에서 만든 사용자 문장이다.
_Avoid_: 내부 점수, 미래 예측

**조건 확인 후보**:
자격이 `conditional` 또는 `unknown`이라 추천을 확정하지 않고 필요한 정보를 확인하도록 남긴 대출 구성이다.
_Avoid_: 추천 대출 구성, 제외 후보

**결과 조건**:
추천 결과를 본 뒤 상품 구성, 생활비 대출, 일반 상환기간, 현재 자격에 필요한 정보와 기존 대출만 확인·변경하는 입력이다.
_Avoid_: 최초 입력, 전체 개인정보 입력

**즉시 재계산**:
결과 조건을 바꾸면 별도 제출 없이 자격, 후보, 시나리오 자금과 상환 원장을 한 번에 다시 만드는 동작이다.
_Avoid_: 표시값만 변경, 부분 미리보기

**제외 후보**:
현재 입력과 공식 정책으로 자격이 `ineligible`임이 확인되어 기본 추천 후보에서 제외된 대출 구성이다.
_Avoid_: 조건 확인 후보, 승인 거절

**자격 예외**:
기본 자격을 충족하지 못하는 경우에도 확인된 정책 조건에 따라 자격 기준을 달리 적용하는 규칙이다. 이자면제나 상환유예와 분리한다.
_Avoid_: 이자면제, 상환유예

**이자면제**:
정책이 정한 대상 원금과 기간의 이자를 면제하는 특례다. 대출 자격을 부여하거나 상환을 유예하는 규칙은 아니다.
_Avoid_: 자격 예외, 상환유예

**상환유예**:
정책 조건에 따라 의무상환 개시나 납부를 미루는 특례다. 대출 자격이나 이자면제를 뜻하지 않는다.
_Avoid_: 자격 예외, 이자면제

**일반 상환 월 납입액**:
거치 후 정한 상환기간 동안 원리금균등으로 매월 납부하는 계획 금액이다. 취업 여부와 무관한 약정 상환액이다.
_Avoid_: 취업후 연간 의무상환액, 월평균 환산액

**졸업 후 준비기간**:
예정 졸업 뒤 일반 상환의 원리금 상환을 시작하기 전까지 이자만 내는 기간이다. 기본값은 1년이며 실행 시점부터 예정 졸업까지의 기간과 합쳐 공식 거치 상한을 적용한다.
_Avoid_: 취업 지연기간, 전체 거치기간

**학기별 상환 일정**:
일반 상환의 각 대출 실행분에 대해 실행일, 거치이자 납부 구간, 원리금 상환 시작·종료일과 월별 잔액을 계산한 일정이다. 여러 실행분은 같은 달의 납입액과 잔액을 합산하되 개별 약정은 유지한다.
_Avoid_: 전체 원금을 한 번에 실행한 단일 상환표

**상환 결과 원장**:
선택한 구성의 용도별 원금, 상품별 실제 상환 단위, 10년 이자·잔액, 학기별 실행과 계산 정책근거를 한 흐름으로 보여주는 결과 영역이다.
_Avoid_: 상품 단위가 섞인 월 납입액, 내부 점수표

**거치이자**:
일반 상환 실행일부터 원리금 상환 시작 전까지 실행분 원금에 매월 발생하고 납부하는 이자다. 원금에 더해 복리로 계산하지 않는다.
_Avoid_: 상환기간 이자, 원금에 가산된 이자

**취업후 연간 예상 의무상환액**:
현재 총급여 환산액과 정책 기준·상환율로 추정한 한 해의 의무상환액이다. 실제 연간소득금액을 사용한 확정 납부액은 아니다.
_Avoid_: 고정 월납입액, 일반 상환 월 납입액

**월평균 환산액**:
취업후 연간 예상 의무상환액을 월 생활비와 비교하기 위해 12로 나눈 참고값이다. 실제 월별 청구액이나 약정 납입액을 뜻하지 않는다.
_Avoid_: 월 납입액, 월별 청구액

**상환부담 월평균 환산액**:
혼합 구성의 스트레스 비교에서 일반 상환 월 납입액과 취업후 연간 예상 의무상환액의 월평균 환산액을 더한 참고값이다.
_Avoid_: 실제 월 청구액, 상품별 상환액을 합친 약정액

**현재 기준 10년 단순 비교**:
취업 후 120개월 동안 현재 입력한 소득과 계산 기준연도의 상환기준소득·정책금리를 변하지 않는 값으로 두고 상환부담을 비교한 결과다. 실제 미래 예측이나 확정 상환액이 아니다.
_Avoid_: 10년 예측, 미래 상환액

**계산 추적 원장**:
필요자금부터 현재 월소득, 이번 학기 대출 실행, 거치이자와 상환까지 계산 순서와 반올림 전 값을 보존한 `calculationTrace`다.
_Avoid_: 화면 표시값, 계산 요약

**비교 시나리오**:
현재 중시·균형·미래 중시처럼 생활비 여력과 상환부담의 관계를 비교하는 안이다. 추천 여부는 시나리오가 아니라 그 안의 대출 구성에 붙는다.
_Avoid_: 추천 시나리오, 확정 대출안

**시간축 월 생활비 여력**:
재학 중 현재 월소득에 이번 학기 생활비 대출의 6개월 배분액을 더하고 해당 월 상환부담을 뺀 금액이다. 취업 후에는 월소득에서 상환부담을 뺀다. 취업 지연 기간에는 소득과 추가 차입을 0으로 두므로 별도 생활비 확보를 뜻하지 않는다. 희망 생활비는 차감하지 않는다.
_Avoid_: 희망 생활비 대비 여유·부족액

**시간축 남은 대출잔액**:
일반 상환 월 원장의 월초 잔액과 취업후상환 잔액을 합한 값이다. 취업후상환은 취업 전 기존 월 복리 규칙, 취업 이후 최근 연간 결산 잔액을 사용한다. 연간 결산 사이 월별 확정 잔액을 예측하지 않는다.
_Avoid_: 해당 월 상환액

**비교 대상과 상세 대상**:
비교 대상은 서로 다른 두 시나리오이며 상세 대상은 그중 하나다. 상세 대상 선택은 그래프의 두 선을 바꾸지 않는다. 기본·변경 조건 보기는 그래프·표·상세에 공통 적용한다.
**내 시나리오**:
사용자가 기존 안을 복사해 이번 학기 생활비 금액·상품·기간을 직접 정한 비교안이다. 자동 추천안이나 승인 결과가 아니며 추가·수정·삭제할 수 있다.

**학기당 생활비 대출액**:
해당 학기에 실행할 생활비 원금이다. 0원 또는 최소 10만 원부터 5만 원 단위로 정하고 학기·누적 한도를 적용한다. 월 배분액은 이 원금을 해당 학기 개월로 나눈 생활비 사용 가정으로, 매월 신규 대출을 뜻하지 않는다.

**조회 시점 고정**:
그래프의 의미 있는 점을 클릭·터치해 선택한 날짜를 유지하는 동작이다. 마우스를 옮겨도 유지되며 이전/다음·방향키로 바꾼다. 전체 월별 값은 표에서 확인한다.


**등록금 자기자금 여유**:
낼 수 있는 등록금 자기자금 중 실제 납부에 사용하지 않고 남겨두는 금액이다. 등록금 대출은 학교 납부용이며, 이 여유자금을 생활비나 운용수익에 자동 합산하지 않는다.

**이번 학기 생활비 막대**:
현재 월소득+생활비 대출÷6의 상환 차감 전 금액이다. 월별 실제 현금흐름 원장의 상환 후 생활비와 구분한다.

상환 후 월소득 막대와 상세 요약은 일반 원금 상환 시작·취업 중 늦은 시점부터 12개월을 사용한다. 일반 대출이 없으면 취업 첫 12개월이다. 혼합 상품도 같은 관찰 기간의 실제 원장을 합산한다. 각 안의 상품·용도, 현재부터 경과 개월 및 월평균 상환액을 표시한다. 취업 후 상환은 같은 소득이면 초기 상환액이 같을 수 있으며 잔액·상환 완료 시점으로 차이를 확인한다.
