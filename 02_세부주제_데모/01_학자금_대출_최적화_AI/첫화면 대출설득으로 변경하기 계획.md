# 첫화면 대출설득으로 변경하기 계획

이 문서는 사용자가 지정한 제목으로 보관하는 **설계 합의 기록**이다. 완료·보류 작업 목록은 유지하지 않으며, 현행 동작·검증은 [PRODUCT.md](PRODUCT.md), 시각 기준은 [DESIGN.md](DESIGN.md), 구조는 [ARCHITECTURE.md](ARCHITECTURE.md)를 따른다.

## 확정 구성: 2안

이미지 시안의 원형 배치와 은은한 그라데이션을 참고한다. 문구는 이미지가 아니라 아래 사용자 원문을 사용한다. 다섯 제목과 설명을 항상 노출하며 + 버튼·아코디언·‘상세 설명’ 펼치기를 사용하지 않는다. 1안과 혼합하지 않는다.

데스크톱은 큰 원의 제목과 옆의 설명을 좌우 교차 배치한다. 모바일은 제목 다음에 설명이 이어지는 한 열로 구성한다. 후속 요청에 따라 각 후킹 구역 높이를 기존의 약 1.45배로 늘리며, 초기 전체 1.5스크린 목표보다 구역별 여백을 우선한다. 오른쪽 제목은 원 안쪽으로 우측 이동하고, 모바일에서는 한 열의 정렬을 유지한다. 원의 장식은 화면 가장자리에서 잘릴 수 있지만 글자는 잘리지 않아야 한다. 이미지의 변형 후킹이나 누락된 항목은 채택하지 않는다.

## 브랜드와 메인 영역

- 좌상단: `SLOW`만 표시
- 메인 제목: `학자금 대출, SLOW로 만나보세요`
- 메인 부제: `Student Loan Operating Window`

## 후킹 멘트: 다섯 항목과 순서 유지

1. 대출이 무섭니?
2. 대출로 대학시절 시간을 버는 원리
3. 학자금 대출만의 이점
4. 소비 평탄화란?
5. 등록금 낼 여력이 있어도, 대출을 고려해야하는 이유는 뭘까요?

원래 네 항목에 등록금 여력 질문을 추가한 것이다. 다섯 제목은 같은 위계이며 등록금 질문을 메인 제목으로 올리거나 작은 보조 문구로 낮추지 않는다. 원문에 있었던 +는 과거 1안의 버튼 표기였으며 확정 구성에는 포함하지 않는다.

후속 요청으로 제목의 괄호 문구는 제거했다. 각 제목 옆에는 짧은 설명을 항상 표시한다. 대출의 활용 이유와 현재·미래의 상환 관계를 설명하고 위험이 없다고 단정하지 않는다. 등록금 대출과 생활비 대출을 구분한다. 등록금 여력이 있는 경우에는 자기자금 지출 시점과 대출 비용을 함께 설명하며, 보유 자금 운용수익은 계산하지 않는다.

## 하단의 공식 요건 확인

작은 버튼 문구는 `실제 학자금 대출 상세 요건 알아보기`다. “나는 얼마나 덜 일하고, 얼마를 갚게 될까요?”와 대형 설득 배너는 사용하지 않는다. 사실을 확인하는 영역이므로 간접적인 설득 문구를 붙이지 않는다.

이 버튼은 기존 팝업 방식을 재사용해 등록금 대출의 공식 조건을 보여준다. 후킹 설명을 팝업으로 숨기지 않는다. 팝업에는 상품 구분, 신청 자격, 등록금 범위·부분대출·한도, 금리·상환, 중복지원과 일정, 기준학기·확인일·공식 출처를 제공한다.

## 범위

첫 화면과 공식 요건 팝업을 변경한다. 기존 계산기와 결과 화면 전체를 재디자인하거나 계산 로직을 변경하는 요청은 아니다. 이미지 생성은 추가로 진행하지 않는다.
