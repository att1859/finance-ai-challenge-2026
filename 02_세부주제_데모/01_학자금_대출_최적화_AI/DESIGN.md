# SLOW 디자인 기준

SEED는 비활성화했다. UI 설계와 검수는 Impeccable을 사용하며 입력·선택의 기존 기능은 프로젝트 소유 controls.js/controls.css로 유지한다. 이번 전환은 도구와 의존성 변경이며 전체 화면 재디자인은 별도 작업이다.

## 색상과 서체

종이색 #f4f3ee, 보조 종이색 #ebeae4, 흰 면 #fffefa, 남색 #091622, 본문 보조 #243341, 설명 #65717a, 경계 #c9ccc8/#8e9799를 유지한다. 파랑 #315f7a는 계산 정보, 장미색 #a54d42는 오류·부족, 호박색 #865b13은 주의에 사용한다. 라임 #c9ef3c는 제한적인 행동 강조에만 쓰며 선택 카드에 형광 링을 만들지 않는다. 키보드 포커스는 #1769aa다.

Pretendard UI 번들 서체와 Malgun Gothic·시스템 산세리프 폴백을 사용한다. 외부 서체 CDN을 추가하지 않는다. 본문·입력 값은 16px, 보조·단위·제어 레이블은 최소 14px다. 제목 위계는 기존 화면을 유지하고 금액은 tabular-nums로 정렬한다.

## 모서리와 상태

| 대상 | 공통 토큰 | 프로젝트 값 |
| --- | --- | --- |
| 버튼·입력·선택 카드 | --radius-control → 8px | 8px |
| 비교·안내 면 | --radius-surface → 12px | 12px |
| 상세·다이얼로그 | --radius-detail → 16px | 16px |
| 체크박스·작은 표식 | 4px | 4px |
| 라디오·장식 원 | 50% | 원형 |

같은 컴포넌트는 모바일에서도 같은 반경을 사용한다. 반응형 CSS에서 카드의 border-radius를 0으로 바꾸거나 비대칭 모서리를 추가하지 않는다. 새 반경 값은 공통 토큰에서 정의한다.

선택 카드는 1px 단일 테두리의 색과 약한 표면 차이, 라디오 점으로 표시한다. 선택 상태에 안쪽 그림자·형광 링·이중 테두리를 겹치지 않는다. 키보드 포커스는 별도 외곽선이며 카드와 내부 라디오에 동시에 표시하지 않는다. 정적인 면에는 드롭 섀도를 사용하지 않는다.

## 공통 컴포넌트

버튼은 프로젝트 자체 버튼 스타일를 사용한다. 주요 행동은 neutralSolid, 보조 행동은 neutralWeak이며 독립 조작 영역은 최소 44px다. 기존 .button 행동도 공통 어댑터가 recipe를 적용한다. 기능 추가 시 별도 버튼 스킨을 만들지 않는다.

입력·select는 프로젝트 자체 입력 표면으로 감싼다. 단위는 같은 표면 오른쪽에 표시하며 문자와 겹치지 않는다. 오류는 인접 설명과 장미색 경계, 포커스는 파란 외곽선을 사용한다. disabled와 오류를 색만으로 전달하지 않는다.

세그먼트는 프로젝트 자체 선택 그룹의 하나의 인디케이터를 사용한다. radio는 원형, checkbox는 작은 라운드로 단일·복수 선택을 구분한다. 화살표 키·Tab·Space의 의미를 유지한다.

단순 정보에 컨테이너를 추가하지 않는다. 상세 제목 옆 상환방식은 테두리·배경 없는 보조 텍스트다. 비교 A/B 상품도 각 안 아래 평평한 텍스트로 표시한다. 라벨이라는 이유만으로 카드나 pill을 만들지 않는다.

## 화면 구성

페이지 최대 폭은 1180px다. 입력은 6개 필드의 2열, 모바일에서는 1열이다. 계산 후 상환방식 안내 → 비교 그래프 → 내 조건으로 상품 확인 → 입력 완료 후 상세 대상·상품 선택 → 계산 요약 → 접힌 내역 순서를 유지한다. 1080/820/580/360px 배치를 사용하며 모바일에서도 카드 반경을 유지한다.

첫 화면은 SLOW 제목과 PRODUCT.md의 다섯 소개 항목을 상시 노출한다. 소개 영역에만 연한 라임·청색·민트 그라데이션 원과 좌우 교차 배치를 허용한다. 설명 행은 데스크톱 최소 258px, 모바일 350px이며 기존 여백을 유지한다. 공식 요건은 작은 버튼으로 native dialog를 연다.

상환방식 안내 제목은 “갚는 방식에는 2가지가 있어요”다. “변동금리”는 밝은 빨간 텍스트, “금리가 나중에 바뀔 수 있어”는 밑줄로 강조한다. 완료 문구와 형광 배경은 사용하지 않는다.

생활비 비교는 A/B/NO 대출 막대, 대학 생활비 희망액은 점선이다. 상환 부담·잔액은 시간축 선과 최대 4개 X축 눈금을 사용한다. Y축은 전체 값과 0을 포함한다. 그래프 높이 320–490px와 안내·범례 공간을 유지해 지표 전환 이동을 줄인다. 모든 지표에 A/B 용도별 상환방식을 표시한다. 클릭·키보드 시점 조회와 표의 값·단위를 일치시킨다.

상세 제목 오른쪽 상환방식은 모바일에서 제목 아래로 이동한다. 자격 입력은 공통 확인과 조건별 질문으로 구성한다. 월별 상세 장표는 없으며 비교 그래프의 표는 유지한다. 상품 표는 최대 760px, 금액만 오른쪽 정렬하며 모바일에서는 용도별 세로 항목으로 바꾼다. 시나리오 자체를 추천·정답으로 표시하지 않는다. 세부 계산·정책·문구는 PRODUCT.md를 따른다.

Impeccable은 활성화 상태다. 디자인 기준 변경은 사용자가 요청한 범위에서만 수행한다.

공통 체크박스에는 확인 필요/미충족 보조 줄을 표시하지 않아 체크 전후 높이를 유지한다. 자격 입력 중에는 작성 상태만 갱신하고 입력 요소의 화면상 위치와 포커스를 보존한다. 계산 반영은 입력 완료 버튼으로 실행한다. Pretendard 로컬 가변 폰트는 한글 완성형 전체와 자모를 포함하며, Pretendard 1.3.9 원본의 SIL OFL 라이선스를 assets에 함께 보관한다.

현재 전체 UI 글꼴은 Pretendard Variable(1.3.9, 100–900) 로컬 웹폰트다. 다운로드 폴더의 전체 woff2와 라이선스를 assets에 복사했으며 축소 글꼴에 없는 한글로 인한 대체 글꼴 혼용을 해소한다.

개별 요건의 모름/확인 필요 선택지는 제거한다. 학적과 지원구간은 값을 임의 확정하지 않고 선택 안내를 표시하며, 라운드 메뉴의 실제 선택지에는 안내 항목을 넣지 않는다. 학적·지원구간 메뉴는 키보드 방향키·Enter·Escape를 지원한다.

개별 요건의 학점·졸업학년·학교 예외·미혼·긴급생계곤란 질문은 답변에 따라 제거하지 않는다. 적용되지 않을 때 입력을 비활성화하고 고정 설명 영역에 이유를 표시하며 기존 응답은 보존한다. 일반상환 성적 확인도 비적용 시 비활성화하고 모두 체크에서 제외한다.

입력 완료 후 상환상품 네 구성은 일반/일반, 일반/ICL, ICL/일반, ICL/ICL 순서로 유지한다. 작성 중에는 카드를 숨긴다. 자격 미충족 카드는 회색 표면·미충족 문구·사유와 disabled 라디오로 표시한다. 미확인 후보는 선택 가능 상태로 구분하며, 기존 선택이 미충족으로 바뀌면 그래프의 가정 유지 사실을 안내하고 자격 입력 링크를 제공한다.


## 자격 입력 완료 흐름

학적·지원구간과 기본값/미체크 항목의 최종 확인을 필수로 받는다. 연령 예외를 주장하면 필요한 실제 나이를 확인한다. 미입력은 가까운 오류 문구와 첫 항목 포커스로 안내하며 자격 미충족은 입력 완료를 막지 않는다. 완료하면 한 번 재계산하고 입력칸을 접어 학적·지원구간 요약과 정보 수정 버튼을 남긴다. 상품 선택 제목을 완료 버튼 근처에 배치하며 포커스를 옮긴다. 수정 중에는 이전 확정 결과와 미반영 상태를 표시하고 다시 완료하기 전까지 계산에 반영하지 않는다.
