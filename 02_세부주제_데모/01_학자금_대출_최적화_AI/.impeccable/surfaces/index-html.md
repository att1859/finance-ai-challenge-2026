# 학자금 소비평탄화 AI

## Scope

- Target route: `index.html`
- Audience: 졸업까지 남은 기간 동안 생활비·학업시간·근로·학자금대출의 교환관계를 비교하려는 대학생
- Primary task: 직접 또는 예시 정보로 조건을 입력하고 세 계획 중 하나를 선택해 통합 비교, 선택안 상세, 자금배분과 위험 변화를 검토한다.
- Product boundary: 브라우저 세션에서 작동하는 간이 계산 데모이며 장학금 수혜, 대출 자격·승인, 금융·법률 자문을 확정하지 않는다.

## Direction contract

- Thesis: 사용자가 세 가지 계획을 직접 고르고 동일 축의 통합 비교에서 대학 생활의 시간과 졸업 후 부담을 함께 읽는 **selectable comparative ledger**다.
- Visual world: 따뜻한 종이색 `#F4F3EE`, 심해색 원장 `#091622`, 행동·선택 전용 라임 `#C9EF3C`를 사용한다.
- Form metaphor: 현금흐름 배분 원장을 기능 구조로 번역한 code-led operate 방향이다. Grounded candidate 6, seed `f751399c`.
- Anti-reference: KPI 카드형 대시보드, 자동 추천 점수판, 독립 거대 숫자, 그라디언트, 글래스모피즘, 장식적 AI 표현을 거부한다.
- Material: 흰 종이면, 얇은 규칙선, 비대칭 남색 원장, 선택된 안의 라임 안쪽 링으로 위계를 만든다. 드롭 섀도는 사용하지 않는다.

## Story and hierarchy

화면의 서사는 다음 순서를 보존한다.

`입력 → 시나리오 선택 → 세 지표 통합 비교 → 선택안 상세 → 필요자금 원장 → 지원사업 정보 → 스트레스 → 공식 출처와 경계`

사용자가 선택을 바꾸면 통합 비교의 강조, 선택안 상세, 자금 원장, 스트레스 계산과 스크린리더 상태 메시지가 함께 바뀐다. 균형형은 최초 표시되는 “기본 보기”일 뿐 추천이나 최적안이 아니다.

## First viewport

- 왼쪽은 “대학 생활과 졸업 후 부담을 한 번에 비교해 보세요.”라는 단일 약속, 계산 CTA, 예시 정보 진입, 브라우저 세션 개인정보 경계로 구성한다.
- 오른쪽은 금액을 과시하는 KPI가 아니라 세 계획에서 달라지는 대학 생활비 여력, 주당 근로시간, 상환 후 생활비 여력을 번호가 붙은 남색 원장으로 예고한다.
- 1180px 컨테이너 안에서 두 열을 유지하고, 820px 이하에서 약속 다음에 세 비교축 원장이 이어지는 1열 흐름으로 바꾼다.

## Input and calculation axes

- 입력은 직접 입력과 예시 정보의 두 모드를 제공한다.
- 폼은 재학 정보, 학비와 확정 지원 정보, 생활과 근로, 대출 계획의 네 행형 구획으로 구성한다.
- 졸업까지 남은 기간은 0.5–8년 범위의 0.5년 단위이며 입력 즉시 학기와 개월로 환산해 보여준다. 이 값은 총필요자금, 대출 실행 횟수, 재학 중 이자의 계산축이다.
- 학기당 등록금은 장학금·감면 반영 후 실제 납부액이며, 생활비성 지원금은 졸업 전까지 수혜가 확정된 총액만 입력한다.
- 대출유형은 일반 상환과 취업 후 상환 중 선택한다. 일반 상환은 거치·상환기간과 원리금균등·원금균등을, 취업 후 상환은 기준연도·상환기준소득·의무상환율을 사용한다.
- 오류는 필드 인접 문구와 `aria-invalid`를 함께 표시하고 첫 오류 필드로 포커스를 옮긴다.

## Scenario selection and grouped comparison

- 선택 그룹은 학업시간 확보형, 균형형, 부채 최소형을 같은 크기와 문장 구조의 라디오 옵션으로 제시한다.
- 균형형에는 “기본 보기”만 붙이고, 현재 사용자가 고른 안에만 “내 선택”, 라임 라디오, 3px 안쪽 링을 적용한다.
- 통합 비교 figure는 대학 시절 월 생활비 여력, 주당 근로시간, 상환 후 월 생활비 여력의 세 행을 같은 자리에서 보여준다.
- 막대 길이는 각 지표 안에서만 비교하며 희망 기준과 근로시간 현재 기준을 점선으로 표시한다.
- 동일한 값과 단위를 접근 가능한 표로도 제공하고, 선택 변화는 `aria-live` 상태 메시지로 알린다.

## Selected detail and funding

- 선택안 상세는 비대칭 남색 원장 안에서 대학 생활비, 시나리오 근로시간, 상환 후 생활비, 졸업 시 대출잔액을 먼저 보여준다.
- 이어 대출유형에 맞는 첫 달·월평균·총이자·첫해 상환 또는 연간 의무상환·월 환산·기준소득·예상잔액을 표시한다.
- 자금 원장은 졸업기간을 학기·개월로 연결하고 등록금과 희망 생활비를 합산한 뒤 확정 생활비성 지원금, 선택안 근로소득, 신규 대출만 차감한다.
- 지원사업 카탈로그의 후보 금액은 정보 제공용이며 계산에서 차감하지 않는다. 수혜가 확정되면 사용자가 확정 지원금 입력값에 반영한다.

## Stress, sources, and boundaries

- 스트레스 조건은 취업 6·12개월 지연, 초봉 20% 감소, 졸업 1년 지연을 조합해 현재 선택안만 다시 계산한다.
- 결과는 대학 생활비 여력, 대출유형에 맞는 상환액, 상환 후 생활비 여력과 기준 대비 변화를 같은 행에 보여준다.
- 출처는 일반 상환과 취업 후 상환의 한국장학재단 공식 안내를 분리하고 기준일을 기록한다.
- 세금, 물가 변화, 자발적 중도상환, 실제 심사 결과가 제외됨을 밝히고 자동 설명·규칙 점검·계산식과 공식기관의 최종 판단 경계를 유지한다.

## Visual system

- 한국어 UI는 번들된 `src/assets/NotoSansKR-UI.woff2`를 100–900 가중치와 swap 방식으로 로드한다. 외부 폰트 CDN에 의존하지 않는다.
- 기본 표면은 따뜻한 종이와 흰 면, 핵심 상세는 깊은 남색, 선택과 단계만 라임이다.
- 필드는 6px, 버튼은 7px, 선택 면은 8–12px, 핵심 남색 원장은 좌하단 4px의 비대칭 모서리를 사용한다.
- 포커스는 선택 라임과 구분되는 3px 파란 외곽선으로 표시한다.

## Responsive and accessibility

- 기본 컨테이너는 최대 1180px, 데스크톱 좌우 안쪽 여백은 28px이다.
- 1080px에서는 첫 화면의 두 열을 유지하되 간격을 줄이고 3열 입력을 2열, 선택 상세 지표를 2열, 출처를 2열로 바꾼다.
- 820px에서는 탐색 링크를 숨기고 첫 화면·폼·결과 소개·시나리오 선택·대출 상세·스트레스를 1열로 전환한다. 비교표는 가로 스크롤을 허용한다.
- 580px에서는 좌우 여백을 18px로 줄이고 비교 figure와 선택 상세를 화면 가장자리까지 확장하며 제어와 데이터 그룹을 대부분 1열로 쌓는다.
- 360px에서는 좌우 여백을 15px로 줄이고 선택 상세 지표를 1열로 바꾼다.
- 버튼은 48px, 큰 CTA는 56px이며 체크·분할·초기화 행동은 최소 44px를 유지한다. 본문 바로가기, 키보드 라디오, 첫 오류 포커스, 선택 상태 알림, 접근 가능한 비교표를 보존한다.
- `prefers-reduced-motion`에서는 부드러운 스크롤과 전환을 제거하고 애니메이션을 사실상 즉시 완료한다.

## Guardrails

- 사용자 선택보다 자동 추천을 앞세우지 않고 균형형을 정답처럼 표현하지 않는다.
- 후보 장학금과 후보 지원액을 확정 금액처럼 계산에 반영하지 않는다.
- 세 지표를 서로 다른 화면이나 독립 KPI 카드로 흩지 않는다.
- 졸업기간과 대출유형이 계산 결과를 바꾸는 축임을 숨기지 않는다.
- 그라디언트, 글래스모피즘, 드롭 섀도, 장식적 AI 스파클을 추가하지 않는다.
- 공식 출처, 계산 가정, 미반영 후보, 금융서비스 경계를 결과에서 멀리 떼어내지 않는다.
