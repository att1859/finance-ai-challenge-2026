## Product Purpose

사용자가 입력한 실제 납부 등록금, 대출 없이 낼 등록금, 학자금 지원구간, 근로조건과 졸업까지의 기간을 기준으로 세 계획의 현재 생활 여력과 졸업 후 부담을 한 자리에서 비교한다. 시나리오 자체를 정답으로 추천하지 않고, 사용자가 고른 시나리오 안에서 자격·충족·안전 규칙에 맞는 대출 구성을 추천해 선택의 교환관계와 계산 경계를 투명하게 보여주는 간이 계획 도구다.

## Operating Context

사용자는 직접 또는 예시 정보로 조건을 입력한 뒤 최소대출안, 균형안 v1, 최대활용안 중 비교할 안을 직접 선택한다. 화면은 대학 시절 월 생활비 여력, 주당 근로시간, 상환 후 월 생활비 여력을 통합 비교하고, 선택한 시나리오 안의 추천·조건 확인 대출 구성과 자금배분·상환·위험 조건을 이어 보여준다. 균형안 v1은 최초 표시되는 시나리오 기본 보기일 뿐 추천 시나리오가 아니다.

## Capabilities and Constraints

- 최소대출안은 현재 근로시간에서 생활비 부족분만, 최대활용안은 공식 생활비 학기·누적 한도 안에서 희망 생활비를 지킬 수 있는 가장 낮은 근로시간의 부족분만 빌린다. 균형안 v1은 두 안의 최대 근로시간 감소량 중 50% 지점을 0.5시간 단위로 계산하며, 주 15시간 주휴수당 경계를 포함해 모든 후보를 다시 계산한다.
- 등록금 원금은 학기당 실제 납부액에서 대출 없이 낼 금액을 먼저 뺀 뒤 학기별 실행분으로 만든다. 생활비 신청액은 공식 최소액·5만 원 단위·학기 200만 원·학제별 누적한도를 적용하고 부족분은 `unmetLivingGap`으로 남긴다.
- 공식 생활비 한도 전액은 세 비교 시나리오의 계산액과 섞지 않고 `풀대출 상한 보기`로 별도 반환하며 추천 대출액으로 표시하지 않는다. 최대 근로시간 감소가 0인 경우 금액과 근로시간이 같은 시나리오는 반복하지 않는다.
- 최초 입력 화면에서는 학기당 실제 납부 등록금, 그중 대출 없이 낼 등록금과 학자금 지원구간을 받는다. 대출상품, 생활비 대출 여부, 거치·상환기간, 특례와 기존 대출은 최초 입력에서 요구하지 않는다.
- 결과에서 각 시나리오의 가능한 네 상품 구성을 고르고 생활비 대출 포함 여부를 바꿀 수 있다. 선택 구성에 일반 상환이 있을 때만 졸업 후 준비기간 0·1·2년과 상환기간 1–10년을, 현재 자격 판정에 정보가 부족할 때만 학제·나이·학적·성적·학점·공통요건과 관련 특례를 보여준다.
- 기존 학자금대출은 결과에서 사용자가 있다고 선택한 경우에만 상품과 잔액 입력이 나타난다. 공식 한도 전액은 선택 구성과 분리된 `풀대출 상한 보기`로 접어 제공한다.
- 결과 조건이 바뀌면 별도 제출 없이 선택한 상품 구성과 생활비 포함 여부를 시나리오 계산에 다시 넣는다. 자격·추천 후보, 근로시간 감소량, 미충족 생활비, 학기별 실행분, 거치·상환 일정과 현재 기준 10년 결과를 함께 갱신하고 스크린리더 상태 메시지로 완료를 알린다.
- 선택 상세 원장은 등록금·생활비별 상품·대출액·자격 상태, 일반 상환의 거치 중 최대 월이자·최초 상환일·원리금균등 월 납입액, 취업후상환의 연간 예상 의무상환액·월평균 환산액을 법적 단위대로 표시한다. 현재 기준 10년 총납부액·이자·말잔액, 학기별 예상 실행일과 실제 계산 정책의 금리 유형·효력일·확인일·공식 링크를 같은 원장에서 확인할 수 있다.
- 추천 설명은 생활비 대출이 만드는 주당 근로시간 감소와 필요한 원금을 보여준다. 근로시간을 유지하면서 생활비가 부족한 경우와 대출 없이 근로시간을 줄이는 경우를 구분하며, 추천 이유에서 내부 규칙 등급·점수 표현을 쓰지 않는다. 자격 미확정 후보는 ‘자격 확인 전 후보’로 표시하고 필요한 정보와 입력 위치를 안내한다.
- 선택 상세의 ‘언제, 얼마를 갚나요?’에서 거치이자·상환 시작일·연간 의무상환액·월평균 환산액의 의미를 각 숫자 옆에 설명한다. 일반 월 납입액이 전체 일정 중 월 합계의 최댓값임을 밝히고, 취업후상환 월평균은 실제 월 청구액과 구분한다.
- `현재 기준 10년 단순 비교`의 기간·불변 가정은 해당 구역에 모으며, 납부액에 이자가 이미 포함됨과 잔액이 10년 뒤에도 갚아야 할 금액임을 설명한다. 변동금리·잔액·생활비 부족은 추천 옆의 주의 구역에, 자격 확인은 별도 안내에 둔다. 신규 대출이 0원이면 학기별 실행 내역의 빈 상태를 명시한다.
- 졸업까지 남은 기간은 0.5년 단위의 0.5–8년 입력이며 학기 수, 생활비 필요 개월 수, 대출 실행 횟수와 재학 중 이자 계산의 축이다.
- 근로소득은 월평균 4.345주를 기준으로 기본급과 주휴수당을 더한 뒤 사용자가 선택한 간편 차감률을 빼서 예상 실수령액을 계산한다. 주휴수당은 주 15시간 이상일 때 주 5일·개근·계속근로를 가정해 `min(주당 근로시간 ÷ 5, 8시간)`으로 추정한다.
- 간편 차감률은 3.3%가 기본이며 4대보험 9.5%, 일용근로 0%를 함께 제공한다. 모두 실제 세금·보험료 확정값이 아닌 시나리오 비교용 추정값이다.
- 대출유형은 일반 상환과 취업 후 상환을 지원한다. 일반 상환은 정책 스냅샷의 금리와 원리금균등으로 고정 월 납입액을 계산하고, 취업 후 상환은 학부·대학원별 상환율과 총급여 환산 기준으로 연간 예상 의무상환액을 계산한다. 취업 후 상환의 월 값은 연간 예상액을 12로 나눈 비교용 환산액이며 고정 월납입액이 아니다.
- 각 시나리오의 신규 대출은 단일 합계 원금이 아니라 등록금·생활비의 학기별 실행분으로 구분한다. 실행분마다 상품, 용도, 원금, 학기, 예상 실행일과 정책근거를 보존하며 상환 계산은 일반 월 납입과 취업후 연간 의무상환을 상품별로 분리한다. 최초 입력 뒤 계산기가 네 혼합 구성을 만들며 상품 선택은 결과 단계로 미룬다.
- 일반 상환은 각 학기 실행분의 실행일부터 거치 중 월이자를 계산하고, 실행 시점에서 예정 졸업까지 남은 기간을 연 단위로 올림한 뒤 졸업 후 준비기간을 더해 상환 시작일을 정한다. 기본값은 졸업 후 준비 1년·원리금균등 상환 10년이며 정책 스냅샷의 거치·상환 최대 10년을 실행분별로 적용한다.
- 일반 상환 결과는 실행분마다 거치이자, 상환 시작·종료일, 월 납입액과 잔액을 보존하고 같은 달의 납입액·원금잔액을 하나의 월별 원장으로 합산한다. 졸업 지연 스트레스에서도 기존 학기 실행분의 약정 시작일은 움직이지 않으며 추가 학기 실행분만 지연된 졸업일을 기준으로 새 일정을 만든다.
- `현재 기준 10년 단순 비교`는 취업 시점부터 120개월 동안 입력한 취업 후 월소득·희망 생활비와 계산 기준연도의 상환기준소득·정책금리를 올리지 않고 유지한다. 일반 상환은 해당 120개월의 월별 납입·이자·잔액을, 취업 후 상환은 10개 연도의 의무상환액·이자·연말 잔액을 계산하며 미래 예측값으로 표현하지 않는다.
- 모든 시나리오와 상품 조합 후보는 필요자금, 월 근로소득, 학기별 생활비 신청 조정, 상품·용도별 실행분, 일반 상환 거치이자, 일반 월별 상환 또는 취업후 연간 상환 순서의 `calculationTrace`를 가진다. 추적 원장은 만 원 단위의 반올림 전 계산값을 보존하고 표시 반올림과 분리된다.
- 계산에 사용한 등록금·생활비 한도, 상품·용도별 자격, 일반·취업후상환 금리와 상환 기준은 `policyReferences`로 분리한다. 각 근거는 `kosaf-2026-2`, 기준학기, 효력일, 확인일, 적용 정책값과 한국장학재단·교육부 공식 출처 URL을 보존하며 추적 원장의 계산 단계가 근거 ID를 참조한다.
- 공식 대출 기준은 런타임 외부 API 없이 `kosaf-2026-2` 로컬 정책 스냅샷에 보존한다. 스냅샷은 학기·효력일·확인일·공식 출처와 상품·용도별 금리, 한도, 자격, 특례, 상환 기준을 포함한다. 현재 계획 결과는 네 상품·용도 조합과 각 실행분의 자격을 `eligible`·`conditional`·`ineligible`·`unknown`으로 판정하며, 입력 화면에서 아직 받지 않는 학적·성적·공통요건은 누락 조건으로 남긴다.
- 자격 기준을 바꾸는 예외, 이자면제, 상환유예는 서로 다른 결과로 반환하고 시행일과 공식 정책근거를 함께 보존한다. 이 판정은 현재 입력과 정책에 따른 계획용 확인이며 실제 신청 승인 결과가 아니다.
- 각 시나리오는 공식 허용된 네 등록금·생활비 상품 조합을 별도 후보로 계산한다. `ineligible`만 제외하고 자격·자금충족·시나리오 목표·졸업 후 생활비 안전성 규칙을 먼저 적용하며, 같은 규칙 등급에서만 현재 기준 10년 총납부액 45%·잔액 35%·초기 월평균 부담 20%의 내부 점수로 정리한다.
- 내부 점수는 결과 계약이나 화면에 노출하지 않는다. 최고점 차이가 0.02 이하면 공동 후보로 두고, `conditional`·`unknown` 후보만 남으면 추천을 확정하지 않은 채 필요한 조건과 이유 코드를 반환한다.
- 각 후보는 등록금·생활비별 상품명, 원금, 자격 상태와 누락 조건을 분리한 `compositionDescription`을 제공한다. 추천·주의·제외 이유 코드는 사용자 문장으로 변환되고 해당 후보에 실제 적용한 정책근거 목록을 함께 가진다.
- 스트레스 조건은 취업 6·12개월 지연, 초봉 20% 감소, 졸업 1년 지연을 조합해 선택안의 대학 생활비, 상환액, 졸업 후 생활비를 다시 계산한다. 취업 지연은 일반 상환의 약정 납입 시작을 자동으로 늦추지 않는다.
- 실제 세금·보험료, 연장·야간·휴일근로 가산수당, 물가 변화, 자발적 중도상환, 실제 심사·승인 결과는 계산하지 않으며 정책 스냅샷의 금리와 현재 입력 소득이 유지된다고 가정한다.
- 계산 금리는 사용자가 입력하지 않고 `kosaf-2026-2`의 일반 상환 고정 1.7%, 취업 후 상환 변동 1.7%를 상품별로 사용한다. 첫 화면의 연 3% 예금 및 2.8% 소비자물가 비교는 금리의 크기를 설명하기 위한 참고로만 사용하고 계획 결과에는 반영하지 않는다.
- 입력값과 계산 결과는 브라우저 세션에서만 사용하며 서버에 저장하지 않는다.

## Brand Commitments

- 따뜻한 오프화이트 종이 위에 깊은 남색 원장 면과 얇은 규칙선을 사용해 계산 관계를 먼저 보여준다.
- 라임은 행동, 현재 선택과 규칙형 추천·조건 확인 상태에 제한하고 시나리오의 최초 표시 상태를 추천처럼 과장하지 않는다.

- KPI 카드 묶음, 그라디언트, 글래스모피즘, 장식적 AI 표현보다 행·열·원장·근거 구조를 우선한다.
