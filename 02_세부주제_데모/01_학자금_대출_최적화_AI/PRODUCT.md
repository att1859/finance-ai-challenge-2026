## 목적과 입력

이번 학기 등록금과 생활비 자금을 현재 중시·균형·미래 중시로 나누어 비교한다. 시나리오 자체를 추천하지 않으며 각 안의 가능한 상품 구성을 확인한다.

기본 입력은 구역 구분 없는 단일 폼의 6개 항목이다.

1. 졸업까지 남은 학기: 이번 학기 포함 1–16의 정수. 1학기는 6개월이다.
2. 이번 학기 실제 납부 등록금: 장학금 감면 후 납부액.
3. 대출 없이 낼 수 있는 등록금 금액: 실제 납부액 이하. i 버튼에서 부모님 지원·기존 저축을 설명하며 향후 알바·대출금은 제외하고 생활비 배정액과 중복 입력하지 않도록 안내한다.
4. 현재 월소득: 용돈·기존 소득·저축 중 매달 생활비로 쓸 수 있는 금액. 추가로 할 알바와 대출은 포함하지 않는다.
5. 대학 시절 월 희망 생활비: 기본값 80만 원.
6. 취업 후 예상 월소득: 상환 비교의 소득 가정.

학교·지역·학년·시급·근로시간·세금 및 취업 후 희망 생활비는 입력하지 않는다. 지원구간은 취업 후 상환이 포함된 상품 구성의 결과 추가정보에서 모름/1–10구간으로 받는다. 일반 상환에는 지원구간에 따른 국가 이자면제를 적용하지 않는다. [교육부 공식 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=105052&lev=0&statusYN=W&s=moe&m=020402&opType=N), 확인 2026-09-06.

## 이번 학기 계산 경계

등록금·생활비 대출은 이번 학기에 한 번만 실행한다. 등록금은 즉시 전액 납부하며 분할 납부·향후 알바로 충당하지 않는다. 실제 납부액 T, 낼 수 있는 자기자금 A에 대해 최소 등록금 대출은 T−A, 균형은 T−A/2, 최대는 T다. 실제 사용 자기자금은 T−대출액이고 남겨두는 자기자금은 A−실제 사용액이다. 남겨두는 돈은 생활비에 합산하지 않는다. 남은 학기를 곱해 미래 등록금·생활비 원금을 생성하지 않는다. 남은 학기는 졸업 시점, 취업후상환의 취업 전 이자, 일반상환 거치기간의 기준이다. 졸업 지연도 신규 대출을 자동 생성하지 않는다.

- 현재 중시: 등록금 전액과 이번 학기 생활비 대출 한도를 활용한다.
- 균형: 등록금은 최소 대출과 전액의 중간값, 생활비는 max(0, 월 희망 생활비−현재 월소득)×6을 빌린다. 거치이자를 더 빌리지 않는다. 공식 최소액·신청단위·한도로 희망액과 소폭 다르거나 부족할 수 있다.
- 미래 중시: 등록금 부족분 전액을 빌리고 생활비 대출은 0원이다. 생활비 부족분은 월 추가 알바 시간으로 안내한다.
- NO 대출: 기존·신규 대출이 전혀 없는 별도 비교 기준. 세 시나리오 선택지에 섞지 않고 생활비 막대에 함께 표시한다.

생활비 실행은 0원 또는 최소 10만 원부터 5만 원 단위, 학기 최대 200만 원이며 학제별 누적한도도 적용한다. 부족분을 자동 알바 소득으로 채우지 않는다. 현재 월소득이 희망액 이상이면 균형 생활비 대출이 0원이 될 수 있으며 현재 중시는 여전히 한도 활용이라는 정의를 유지한다. 생활비 포함을 해제하면 해당 안의 생활비 실행만 0원으로 다시 계산한다.

모든 안의 월 추가 알바 시간 = max(0, 월 희망 생활비−현재 월소득−생활비 대출액÷6)×10000÷10320이다. 2026년 최저시급 기준 단순 환산이며 표시에서만 정수 반올림한다. 주휴수당·세금·이자 상환비는 포함하지 않으며 시간을 소득에 자동 합산하지 않는다. NO 대출도 생활비 시간만 환산하며 등록금 부족분은 납부 전에 별도 마련해야 한다고 명시한다. [최저임금위원회](https://www.minimumwage.go.kr/minWage/policy/decisionMain.do), 확인 2026-09-06.

예시: 등록금 400만 원·자기자금 200만 원·희망 월 생활비 80만 원·현재 월소득 50만 원일 때 미래 중시는 등록금 200만 원+생활비 0원·알바 월 약 29시간, 균형은 등록금 300만 원+생활비 월 30만 원(학기 180만 원)·알바 0시간, 현재 중시는 등록금 400만 원+생활비 학기 200만 원이다. 남겨두는 등록금 자기자금은 각각 0·100·200만 원이다.


## 결과와 그래프

비교 A·B는 서로 다른 두 시나리오를 고르며 기본은 미래 중시와 균형이다. 상세 대상은 두 안 중 별도로 선택한다. 내 시나리오 추가·수정·삭제를 지원한다. 사용자 안은 복사한 등록금 전략을 유지하며 이름, 이번 학기 생활비 대출액, 용도별 상품과 일반 상환기간을 저장하며 근로시간은 입력하지 않는다. 직접 금액이 실행 단위에 맞지 않으면 저장을 막고 인접 유효 금액을 안내한다.

대학 생활비와 상환기간 생활비은 두 시나리오와 NO 대출의 막대 3개로 표시한다. 대학 생활비만 희망액 점선을 추가한다. 대학 생활비는 현재 월소득+생활비 대출의 6개월 월 배분액으로 이자·상환 차감 전이다. 실제 이자·상환부담 및 이를 낸 뒤의 금액은 상세에서 별도 표시한다. 각 시나리오의 생활비 부족분·알바 시간도 표시한다. 상환기간 생활비은 아래 상환 기준기간의 월평균 소득−상환부담이다. 취업 후 희망 생활비 충족·부족·안전선 판정과 추천 근거는 제거했다. 상환액이 소득 자체를 초과하는 상태는 구분한다.

상환 부담과 대출잔액은 시간축 선그래프다. 현재부터 기준 졸업+120개월의 고정 관찰 기간을 사용한다. X축 눈금은 최대 4개로 줄이고 Y축은 0과 실제 전체 범위를 포함한 읽기 쉬운 간격으로 잡는다. 두 조건 결과를 함께 고려해 기본/변경 전환 시 축을 유지하며 값을 잘라 숨기지 않는다. 그래프 높이·상단·안내영역을 맞춰 지표 전환의 위치 이동을 줄인다.

시간축 조회는 클릭 고정·이전/다음·방향키·Home/End를 지원한다. 마우스 이동은 조회를 바꾸지 않는다. 월별 원장과 표를 제공한다. 월초 잔액과 해당 월 납입액을 구분하며 일반 월별 약정 원장과 취업후 연간 결산값을 재사용한다. 취업후 연간 의무상환액÷12는 비교용 환산액이다.

취업 지연 0·6·12개월, 초봉 20% 감소, 추가 조건의 졸업 1년 지연을 두 안에 공통 적용한다. 조건 초기화는 취업 지연과 초봉 감소만 초기화한다. 취업 지연 기간의 소득·추가 차입은 0이다.

## 상품과 상환

정책은 kosaf-2026-2 로컬 스냅샷이며 일반 상환 고정 1.7%, 취업 후 상환 변동 1.7%를 사용한다. 금리·한도·자격·특례·상환 기준의 출처·기준일을 실행분과 계산 추적에 보존한다. 상품·용도 네 조합을 독립 평가하고 일반 상환은 원리금균등, 취업 후 상환은 학부/대학원별 연간 의무상환과 월평균 환산으로 구분한다.

일반상환 기본은 졸업 후 준비 1년·상환 10년이다. 실행 시점부터 예정 졸업까지 기간을 연 단위 올림한 뒤 준비기간을 더하고 공식 최대 거치·상환 10년을 적용한다. 기존 약정은 졸업·취업 지연으로 움직이지 않는다. 취업 후 10년 비교의 소득·정책금리·상환기준소득은 고정한다.

결과에서 생활비 포함, 상품, 일반 상환기간, 필요한 자격, 기존 대출을 수정하면 전체 계산을 갱신한다. 자격은 eligible/conditional/ineligible/unknown을 구분한다. 자격 예외·이자면제·상환유예 판정은 서로 분리하며 실제 승인과 다르다. 이자면제는 기존 정책 판정 결과를 유지하며 현행 상환 금액은 정책금리를 고정한 간이 계산이다.

후보는 자격·자금충족·목표·소득 대비 상환 상태를 먼저 평가하고 같은 규칙 등급에서만 10년 납부 45%·잔액 35%·초기부담 20%를 비교한다. 내부 점수는 표시하지 않는다. 0.02 이내는 공동 후보, 조건 미확인은 자격 확인 전 후보로 남긴다. 내 시나리오의 자격 불가 선택은 자동 대체하지 않는다.

## 시각 기준과 검증

기존 종이색·남색·라임·파랑 토큰, 서체, 비교 원장, 반응형 구조를 유지한다. 학기 자금과 졸업시계 분리, NO 대출 정수 시간 표시, 기존 근로입력 무시, 생활비 단위·한도, 상환·자격 테스트를 적용한다. UI 명세는 단일 폼·막대/선 전환·지원구간·내 시나리오 구조를 따른다. 화면은 Codex 내장 브라우저로 검수한다.

## SLOW 첫 화면과 공식 요건 안내

좌상단은 SLOW, 메인 제목은 “학자금 대출, SLOW로 만나보세요”, 부제는 “Student Loan Operating Window”다. 첫 화면은 2안의 원형 그라데이션·좌우 교차 구성이다. 아래 다섯 제목과 짧은 설명을 항상 노출하며 +, 아코디언, 추가 설명 펼치기를 사용하지 않는다.

1. 대출이 무섭니?
2. 대출로 대학시절 시간을 버는 원리
3. 학자금 대출만의 이점
4. 소비 평탄화란?
5. 등록금 낼 여력이 있어도, 대출을 고려해야하는 이유는 뭘까요?

다섯 제목의 위계는 동일하다. 이미지의 변형 문구는 사용하지 않는다. 등록금 납부용 대출과 생활비 지급을 구분하고, 보유 자금 운용수익은 계산하지 않는다.

하단에는 작은 “실제 학자금 대출 상세 요건 알아보기” 버튼만 둔다. 기존 native dialog를 재사용하여 등록금 대출의 범위·부분대출·상품별 나이와 소득 및 학업 자격·한도·상환·중복지원·일정을 표시한다. 공식 확인일은 2026-09-06이며 한국장학재단의 일반 상환·취업 후 상환 소개 및 신청대상 원문을 연결한다. 이는 학기 기준 안내이며 실제 신청 승인 판정이 아니다. 소비평탄화·예금·물가 설명 팝업과 하단 대형 설득 배너는 제거했다.

후킹 설명 행(`slow-topic`)은 데스크톱 최소 높이 258px로 기존 178px의 약 1.45배이며, 오른쪽 제목은 원 안쪽으로 이동했다. 모바일은 최소 높이 350px와 늘어난 상하 여백을 사용하고 가로 이동은 해제한다. 제목의 괄호 문구는 제거했다.

검증(2026-09-06): npm test 79개 통과, npm run build 통과. Codex 내장 브라우저에서 360·720·1440px의 가로 넘침 없음, 막대/선 전환 상단 이동 0px, 지원구간 조건부 표시, 내 시나리오 금액 오류·저장·수정·삭제 및 키보드 시점 조회를 확인했다. UI 회귀 명세를 갱신했으며 Playwright 별도 브라우저 실행은 하지 않았다.

추가 검증(2026-09-06): 등록금 400만 원·자기자금 200만 원·월 희망 생활비 80만 원·월소득 50만 원 예시에서 등록금 대출 200/300/400만 원, 생활비 대출 0/180/200만 원, 월 추가 근로 29/0/0시간을 단위 테스트와 Codex 내장 브라우저에서 확인했다. 남겨두는 자기자금과 이자·상환 부담의 별도 표시, 모바일 360px 가로 넘침 없음도 확인했다.

상환기간 생활비 막대와 상세 요약은 일반 원금 상환 시작·취업 중 늦은 시점부터 12개월을 사용한다. 일반 대출이 없으면 취업 첫 12개월이다. 혼합 상품도 같은 관찰 기간의 실제 원장을 합산한다. 각 안의 상품·용도, 현재부터 경과 개월 및 월평균 상환액을 표시한다. 취업 후 상환은 같은 소득이면 초기 상환액이 같을 수 있으며 잔액·상환 완료 시점으로 차이를 확인한다.

검증: 단위·통합 테스트 80개 및 빌드 통과. 내장 브라우저에서 월소득 350만 원 예시의 일반 상환 344.4/346.0만 원, 두 용도 취업 후 상환 330.6/330.6만 원과 상품 선택 즉시 갱신, 360px 가로 넘침 없음을 확인했다.

잔액·상환 그래프는 일반 약정 종료와 취업 후 상환 완납 시점을 모두 포함한다. 취업 후 상환 연간 결산은 최대 취업 후 50년까지 계산하며 미완납이면 명시하고 잔액을 0으로 만들지 않는다. 10년 추천 비교 원장은 유지한다. 그래프에 각 안의 상환 완료 시점을 표시한다. 같은 소득·상환율의 취업 후 상환 초기 의무상환액은 같으며, 혼합 구성의 일반 납입액 또는 완납 연도의 잔액 한도 때문에 차이 날 수 있다.

검증: 테스트 82개·빌드 통과. 내장 브라우저에서 10년 이후 잔액과 완납 시점의 시간축 확장, 상환기간 생활비 명칭, 모바일 360px 가로 넘침 없음을 확인했다.

계산 후 repayment-guide에서 자동 스크롤을 멈춘다. 일반 상환(고정금리·약정 일정)과 ICL(변동금리·소득 기준)을 짧게 안내하고 그래프로 이어진다. 첫 상품은 등록금·생활비 모두 일반 상환이며 사용자가 바꾼 선택은 유지한다. 그래프→상세 대상 선택→상환상품 메뉴→상세 지표 순서다. 상품 메뉴는 항상 보이고 기간·생활비 포함·자격·기존 대출은 접힌 추가 조건에 둔다. 라디오·세그먼트·선택 카드에는 기존 토큰의 작은 라운드와 명확한 선택·포커스 표시를 적용한다.

졸업 후 준비기간은 비교용 0·1·2·3년 옵션이다. 한국장학재단 일반 상환 소개의 대출기간 상세(2026-09-06 확인)는 잔여재학년수+기본 3년+가산 3년으로 최장거치기간을 산정하며, 기본 3년은 연수·휴학·졸업 후 유예 각 1년이다. 따라서 졸업 후 준비기간의 공식 최대가 3년이라고 표시하지 않는다. 실제 학제·연령 제한은 신청 시 확인하며 앱은 기존 총 거치기간 상한을 유지한다. 근거: https://www.kosaf.go.kr/ko/tuition.do?pg=tuition04_02_01&ttab1=0
