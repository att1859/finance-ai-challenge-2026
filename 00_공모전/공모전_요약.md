# 2026 금융 AI Challenge 공모전 요약

- 조사일: 2026-08-12
- 공식 페이지: https://daker.ai/public/hackathons/2026-finance-ai-challenge
- 주최: 금융보안원
- 주제: 금융 현안을 해결하는 AI 기반 아이디어를 실제 작동 가능한 웹서비스로 구현
- 총상금: 35,000,000원

## 핵심 요구사항

1. 금융 현안을 구체적으로 정의한다.
2. AI 기반 해결 방안과 서비스를 기획한다.
3. 실제 접속 가능한 웹 MVP를 구현한다.
4. 기획서, 기능 명세서, 웹서비스 URL을 제출한다.

문제 탐색 단계에서는 AI 사용 여부로 후보를 제한하지 않는다. 실제 금융 문제가 확인된 뒤, 해결책 선정 단계에서 AI의 필요성과 웹 MVP 구현 가능성을 검토한다.

## 제출물

### 예선

- 제공 양식 기반 기획서 PDF
- 제공 양식 기반 기능 명세서 PDF
- 실행 가능한 웹서비스 URL

### 발표심사 진출팀

- 최종 발표자료 PDF
- 최종 소스코드 ZIP

발표는 PT 15분과 질의응답 5분으로 진행될 예정이다.

## 참가 조건

- 전 국민 참가 가능
- 개인 또는 4인 이내 팀
- 동일인의 개인·복수 팀 중복 등록 불가
- 팀빌딩을 이용했다면 제출 전에 팀장이 팀 전환을 완료해야 함

## 평가와 결격 위험

- 기획서와 MVP를 제출하고 사전검토를 통과한 팀을 비공개 심사위원단이 평가한다.
- 공개된 기준은 공모전 주제 적합성과 부적격 여부 등이며 세부 배점표는 공개되지 않았다.
- 상위 약 11팀이 발표심사 대상으로 선발될 예정이다.
- URL 접근 불가, 제출물 누락, 요청자료 미제출, 부정행위는 결격 사유가 될 수 있다.

## 데이터·권리 조건

- 대회 제공 데이터는 없다.
- 외부 데이터 사용 여부를 공개해야 한다.
- 다른 참가자가 무료로 동등하게 접근할 수 있도록 출처와 접근 방법을 제공해야 한다.
- 외부 코드·데이터·저작물은 라이선스와 출처를 기록해야 한다.
- 타 대회 또는 기존 프로젝트 결과물을 재사용하면 수상 취소 등의 위험이 있다.
- 개인정보와 금융정보를 다루는 아이디어는 실제 정보 없이도 핵심 가치를 검증할 수 있는 MVP 방식을 마련해야 한다.

## 문제 선정 이후 확인할 게이트

1. 실제 국내 금융 문제의 반복 근거
2. AI가 핵심 문제를 해결하는 데 필요한 이유
3. 공개·무료·재현 가능한 데이터
4. 웹 MVP 구현 가능성
5. 저작권·데이터 라이선스·개인정보 적법성
6. 심사 기간 동안 URL을 안정적으로 운영할 수 있는지
