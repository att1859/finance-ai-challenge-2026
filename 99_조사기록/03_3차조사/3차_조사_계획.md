# 3차 조사 계획 — 금융보안과 금융 역량창출

- 확정일: 2026-08-20
- 목적: 정기결제·맞춤형 지원과 별도로 금융보안 및 새로운 금융 판단·운영 기능 후보를 찾는다.
- 방식: 1단계에서 트랙별 최대 3개를 선별하고, 팀이 고른 후보만 2단계 심층 조사한다.

## 1. 조사 트랙

### 금융보안

사기, 이상거래, 정보유출, AI 공격 등 금융 위험을 탐지·예방·대응하고 실제 금융 행동을 바꾸는 서비스다. 범용 이메일 보안이나 일반 관제도구는 제외한다.

### 금융 역량창출

비정형 데이터 결합·분석을 통해 기존에 부족했던 평가, 예측, 매칭, 조사 또는 운영 능력을 제공하는 서비스다. 단순 점수·요약·대시보드가 아니라 새로운 연결이나 실제 행동으로 이어져야 한다.

## 2. 사용자 범위

- 일반 이용자와 업무 이용자를 모두 허용한다.
- 업무 이용자는 금융회사 직원, 보안관제 담당자, 공무원, 심사역, 감사 담당자 등을 포함한다.
- 모든 후보는 `누가 → 무엇을 보고 → 어떤 판단을 내려 → 어떤 행동을 하는지`가 구체적이어야 한다.

## 3. 1단계 후보 조건

1. 공모전 예시를 그대로 복제하지 않고 구체적인 사용자·데이터 연결·행동을 제시한다.
2. 분석 결과가 경고, 차단 요청, 조사 착수, 심사 변경, 대상 연결 또는 공식 실행 준비로 이어진다.
3. 독점 내부 데이터가 없어도 공개·합성 데이터로 핵심 판단과 행동을 시연할 수 있다.
4. 국내 이용자의 반복 수작업, 기존 서비스의 기능 공백 또는 실제 사고 사례 중 하나 이상으로 필요성이 확인된다.
5. 해외 사례는 아이디어 발견에 활용할 수 있지만 국내 업무·데이터·제도에서도 필요가 확인돼야 한다.
6. 최종 후보에는 비정형 데이터 이해, 관계 추론, 이상패턴 탐지 등 AI의 핵심 역할을 표시한다.

## 4. 근거 수집 방식

- 일반 이용자 후보: 커뮤니티, 지식인, 앱 리뷰, 피해 경험을 우선 확인한다.
- 업무 이용자 후보: 실무자 커뮤니티, 사고 분석, 기술 블로그, 학술자료, 업계 보고서, 공개 제안요청서를 활용한다.
- 공식 문서와 뉴스도 사용하지만 그것만으로 후보를 확정하지 않는다.
- 기존 서비스가 있다면 제공 기능, 잘 쓰이는 경우, 대체하지 못하는 이유와 공개근거가 부족한 부분을 구분한다.

## 5. 두 단계 조사

### 1단계 — 간략 선별

금융보안 최대 3개, 금융 역량창출 최대 3개만 제시한다. 각 후보는 다음을 짧게 정리한다.

- 사용자와 현재 업무
- 사용하는 데이터와 현재 수작업
- 새로 만드는 연결·판단
- 결과가 이어지는 실제 행동
- 국내 필요성 근거
- 가까운 기존 서비스와 차이
- 공개·합성 데이터 MVP 가능성
- AI가 맡을 핵심 역할

### 2단계 — 선택 후보 심층 조사

팀이 고른 후보만 사용자 사례, 경쟁 서비스, 데이터·API, 인증·권한, 법적 경계, 실행 단계와 웹 MVP를 철저히 조사한다.

## 6. 기존 후보와의 비교

1단계에서는 정기결제·맞춤형 지원과 순위를 매기지 않는다. 신규 후보 조사가 끝난 뒤 같은 형식으로 두 기존 후보와 비교한다.
