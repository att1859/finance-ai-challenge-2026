# 생존 후보 4개

지금까지의 조사와 토론에서 남긴 네 아이디어만 모은 작업 공간이다. 아직 최종 순위를 정하지 않고, 각 후보의 현재 정의와 검증이 필요한 약점을 같은 형식으로 관리한다.

## 후보 한눈에 보기

| 후보 | 주 사용자 | 핵심 행동 | 현재 초점 | 상세 문서 |
|---|---|---|---|---|
| 맞춤형 지원사업 통합 탐색 | 지원을 찾는 일반 이용자 | 여러 공식 포털의 후보를 한 프로필로 비교하고 정확한 신청처로 이동 | 단순 추천이 아니라 중앙·지역·청년·소상공인 지원의 중복과 실행경로 정리 | [아이디어 정리](./01_맞춤형_지원사업/아이디어_정리.md) |
| 구독 통합 관리 | 여러 결제채널을 쓰는 일반 이용자 | 반복결제를 발견하고 해지·환불의 올바른 주체와 절차로 연결 | 단순 구독목록이 아니라 모호한 가맹점·가입채널·환불경로 해결 | [아이디어 정리](./02_구독_통합관리/아이디어_정리.md) |
| 신종 금융사기 패턴 조기탐지 | 금융회사·감독기관·플랫폼의 사건 분석 담당자 | 비정형 신고를 타임라인화하고 새로운 반복 패턴을 임시 유형으로 즉시 생성·추적 | 사람이 신종 수법을 알아차릴 때까지의 지연 단축 | [아이디어 정리](./03_신종_금융사기_조기탐지/아이디어_정리.md) |

## 공통 문서 형식

각 후보는 다음 항목으로 정리한다.

1. 한 문장 정의
2. 문제와 사용자
3. 서비스 흐름
4. 차별점
5. AI의 역할
6. 데이터·권한
7. 웹 MVP
8. 가장 큰 약점
9. 추가 확인사항

세부 근거와 제외된 후보는 [과거 조사 기록](../99_조사기록/)에 보존한다. 공모전 조건은 [공모전 요약](../00_공모전/공모전_요약.md)을 기준으로 한다.

## 현재 비교 원칙

- 네 후보를 아직 점수나 순위에 맞추지 않는다.
- 기존 서비스와 다른 실제 행동이 무엇인지 먼저 확인한다.
- AI가 없어도 되는 부분은 규칙과 일반 기능으로 둔다.
- 실제 데이터가 없어도 공개·합성 데이터로 핵심 흐름을 보여줄 수 있어야 한다.
- 직접 실행 권한이 없다면 어디까지 단계를 줄일 수 있는지 명확히 표시한다.
