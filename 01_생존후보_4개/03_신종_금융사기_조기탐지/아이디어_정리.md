# 신종 금융사기 패턴 조기탐지

## 한 문장 정의

> 피해자가 제출한 채팅·이미지·가짜 사이트·송금 과정을 사건 타임라인으로 만들고, 식별자가 달라도 반복되는 새로운 범행 흐름을 AI가 임시 유형으로 즉시 생성·추적해 신종 수법을 알아차리는 시간을 줄이는 기관용 분석 워크벤치.

## 문제와 사용자

주 사용자는 금융회사 사기대응팀, 금융소비자보호·신고센터, 감독기관 접수·분석 인력, 플랫폼 신뢰·안전팀이다. 피해자의 신고자료는 채팅 캡처, 가짜 투자화면, 송금내역, URL, 서술문처럼 비정형이고 서로 흩어져 있다.

전화·계좌·도메인은 쉽게 바뀌므로 같은 식별자 조회만으로는 연결이 끊긴다. 기존 유형에 맞지 않는 새로운 범행 흐름은 여러 사건이 쌓인 뒤 사람이 공통점을 알아차릴 때까지 대응이 늦어질 수 있다.

## 서비스 흐름

1. 피해자가 채팅 캡처, 이체내역, URL, 가짜 앱·사이트 화면을 제출한다.
2. AI가 인물·기관·계좌·URL·금액·날짜·요구행위를 추출한다.
3. 증거를 `유입 → 신뢰 형성 → 투자 확대 → 출금 봉쇄`의 표준 사건 타임라인으로 재구성한다.
4. 기존 유형과 비교하고 식별자·문구·화면·진행단계가 비슷한 사건을 연결한다.
5. 기존 유형과 잘 맞지 않지만 서로 닮은 흐름이 반복되면 AI가 업무용 임시 유형을 자동 생성한다.
6. 생성 즉시 과거 사건을 다시 검색하고 이후 신고를 자동 연결하며 담당 큐와 알림을 갱신한다.
7. 담당자는 중요한 임시 유형을 합치기·나누기·기존 유형의 변종으로 편입하거나 공식 유형으로 확정한다.

## 차별점

- 전화·계좌 단건 조회나 스크린샷 한 장의 사기 여부 판별이 아니다.
- 식별자가 달라도 범행 진행순서, 반복 문구, 역할, 가짜 화면, 금전 요구방식을 함께 비교한다.
- 이미 알려진 유형으로 자동 분류하는 데 그치지 않고 반복되는 미분류 흐름을 새 임시 유형으로 만든다.
- 담당자 확인을 기다리지 않고 사건 재검색·자동 연결·우선순위 알림에 임시 유형을 즉시 활용한다.
- 사람 승인은 공식 유형 등록·탐지룰 배포·차단 요청·대외 경고 같은 고위험 조치에만 필수로 둔다.

## AI의 역할

- OCR·문서이해: 여러 형태의 증거에서 개체와 사건단계 추출
- 멀티모달 유사도: 문구·화면·진행수법이 비슷한 사건 후보 생성
- 군집·이상탐지: 기존 유형과 맞지 않지만 서로 닮은 사건의 반복 발견
- 생성형 AI: 임시 유형명, 공통 특징, 기존 유형과의 차이, 연결 근거 설명

동일 계좌·전화·도메인, 날짜 범위와 모순 확인은 규칙으로 보강한다. 임시 유형은 동일 범죄조직이나 신종 범죄의 확정 판정이 아니라 내부 분석을 위한 동적 작업 단위다.

## 데이터·권한

- MVP: 합성 신고, 합성 채팅·가짜 투자화면·이체내역
- 보조자료: 금감원 사례집, 경찰 보도자료, 판결문 등 공개 사례
- 실제 서비스: 피해자 동의와 기관의 법적 근거 아래 접수된 신고 원문
- 보조 신호: 제휴된 더치트 API, KISA WHOIS 등

실제 신고에는 제3자의 전화·계좌·대화가 포함되므로 최소수집·마스킹·짧은 보유기간·권한관리·감사로그가 필요하다. 일반 공개 검색 DB가 아니라 기관 내부 또는 폐쇄형 배포가 적합하다.

## 웹 MVP

- 합성 신고 40건: 알려진 유형 3개, 시간차를 두고 등장하는 신종 패턴 1개, 독립 사건 8건
- 증거 업로드와 자동 사건 타임라인
- 연관사건 비교와 연결 근거
- 임시 유형의 자동 생성, 과거 사건 재연결, 신규 사건 자동 연결
- 신종 패턴 레이더와 캠페인 그래프
- 담당자의 병합·분리·공식화·이관자료 생성 화면

핵심 시연은 신종 패턴 신고가 순서대로 유입되다가 일정한 반복성이 드러나는 순간 AI가 임시 유형을 만들고, 다음 신고부터 담당자 확인을 기다리지 않고 연결·알림하는 장면이다.

## 가장 큰 약점

- 실제 신고 원문과 충분한 사건량을 확보하지 못하면 신종 패턴 발견의 실효성을 검증하기 어렵다.
- 경찰·금감원·금융회사 내부 시스템에 유사한 멀티모달 연관분석이나 신종 유형 탐지가 이미 있을 수 있다.
- 수법 유사성을 동일 조직으로 오인하거나 무관한 사건을 잘못 묶을 위험이 있다.
- 합성 데이터에서 작동하는 결과를 실제 정확도로 과장할 수 없다.
- 외부 SaaS가 신고 원문을 처리하기 어려워 온프레미스·폐쇄망 배포가 필요할 수 있다.

## 추가 확인사항

- 기관 내부 사건관리의 멀티모달 분석·신종 패턴 탐지 범위
- 실제 신고에 반복적으로 첨부되는 증거 유형과 사건량
- 임시 유형을 내부 검색·우선순위화에 즉시 활용할 수 있는 업무 권한
- 새 패턴 발견의 유용성을 평가할 지표와 담당자의 허용 가능한 오탐 수준
- 실제 데이터 없이도 설득 가능한 합성 평가셋 설계
